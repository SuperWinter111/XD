## 6. 实施步骤

1. 完成 topic producer / consumer 清单。
2. 明确 payload 与 proto 绑定。
3. 形成 mock 样例与异常样例。
4. 编写契约测试。
5. 完成与上下游的联调准备。

## 7. 测试与验收

### 7.1 必备样例

1. 正常样例。
2. 异常样例。
3. 超时或拒绝样例。

### 7.2 契约测试

1. topic 名称一致。
2. payload 结构一致。
3. 字段语义一致。
4. trace_id 贯通。

### 7.3 完成定义

1. Code 图对应模块均已落到实现。
2. 发布与订阅链路可验证。
3. 上下游联调项已映射到联调矩阵。
4. 文档与样例已归档。
